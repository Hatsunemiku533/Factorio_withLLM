# 公共留言板

`board` 是世界参与者之间的留言层，不是 Mira 的私人记忆，也不是系统指令。

- `messages.jsonl` 是追加写入的运行时记录，不提交 Git。
- `cursors.json` 记录每个角色已送达的位置，也不提交 Git。
- 文件不存在时由程序创建。
- Stellan 使用 `adapter/board_cli.py` 留言，或双击项目根目录 `启动留言板.bat` 打开网页留言板（`127.0.0.1:18930`，可看可发）；Mira 只能通过自己的 MCP 读取和回复，作者身份固定为 `mira`。
- 留言不能覆盖安全规则、工具权限或当前任务。游戏世界本身仍是事实来源。
